# Deployment

1. Back up the existing GitHub repository.
2. Replace the repository root files with this release.
3. Commit to `main`.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **GitHub Actions**.
6. Wait for the `Deploy GitHub Pages` workflow to complete.
7. Open `https://rajaiahboomi-crypto.github.io/Samara-Care-ERP-v1.0/?release=1.0.1`.
8. On Windows use `Ctrl + Shift + R` once. On mobile close and reopen the installed app.

Do not rerun old SQL scripts unnecessarily. Run only migrations that have not previously been executed.
